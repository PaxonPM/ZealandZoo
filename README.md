# 🦁 Zealand Zoo Event System

This project is a web application made for Zealand Zoo (a student Friday bar).

The purpose of the system is to make it easy to:

- Show opening hours
- Display upcoming events
- Let users sign up for events
- Help admins manage events and basic inventory

---

## 📌 About the System

Zealand Zoo wants a simple platform where students can see what’s happening and plan their visit.

Examples of events:
- Watching football
- Playing games (PC or board games)
- Social activities in the café

Some events have limited spots, so users can sign up to secure a place.

---

## 👤 What Users Can Do

- View opening hours
- See upcoming events
- Switch between list view and calendar view
- Create an account
- Sign up for events
- Cancel their participation

---

## 🔐 What Admins Can Do

- Log in to the system
- Create new events
- Edit existing events
- Delete events
- Set a maximum number of participants
- Manage basic inventory

---

## 📦 Extra Features

- Users can receive notifications about new events
- The system can keep track of inventory (e.g. drinks and items)

---

## 🎯 Purpose of the Project

This project is developed as part of a Datamatiker exam.

The focus is on:
- Creating a useful system for a real case
- Making the system easy to use
- Supporting both users and administrators

---

## 🚀 How to Use

1. Open the application
2. Browse events and opening hours
3. Create an account to sign up for events
4. Admins can log in to manage the system
